# Variational Autoencoder

This project implements a Variational Autoencoder (VAE) using TensorFlow 2.x and Keras.

## Files

- `3-variational.py`: Defines the `autoencoder` function that creates the VAE.
- `3-main.py`: Trains the VAE on the MNIST dataset and visualizes the results.

## Requirements

- Python 3.12
- TensorFlow 2.x
- numpy
- matplotlib

## Usage

Make sure both `3-variational.py` and `3-main.py` are executable:
```sh
chmod +x 3-variational.py 3-main.py
